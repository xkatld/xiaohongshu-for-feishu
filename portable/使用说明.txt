小红书笔记统计台  ·  便携版
==================================================

一、怎么用
--------------------------------------------------
1. 把整个文件夹解压到任意位置（建议放在桌面或 D 盘，路径不要有特殊符号）
2. 双击「启动工作台.bat」
3. 浏览器会自动打开工作台页面（地址通常是 http://127.0.0.1:8787）
4. 按页面顶部的「首次使用 · 四步」引导完成配置（见第二节）
5. 把小红书分享链接粘贴到输入框，点「抓取并保存」

使用期间请保持黑色命令行窗口开着，关掉它就等于停止服务。


二、首次使用：跟着页面上的四步引导做
--------------------------------------------------
本工具是开源项目，每个人使用【自己的】飞书应用、【自己的】飞书账号和
【自己的】小红书 Cookie。它不附带任何人的凭据，也不需要向任何人申请
文档权限——你的数据只会进你自己的飞书空间。

【1】绑定你自己的飞书应用

  点引导卡第 1 步的「去创建」，浏览器会打开飞书官方的应用配置向导：
  - 在向导里按提示创建应用（或者选择你已有的应用）
  - 完成后回到工作台，程序会自动检测并绑定

  也可以手动绑定（适合已经有自建应用的人）：
  打开「设置 → 飞书应用 → 我已有自建应用，手动填写」，
  填入 App ID（cli_ 开头）与 App Secret 即可。
  程序会先向飞书校验，填错了不会写入本机。

  ※ App ID / App Secret 只保存在你自己的电脑（用户目录 ~/.lark-cli），
    不会上传，也不会随本项目分发。

【2】登录飞书

  点第 2 步的「去登录」，会弹出授权链接：
  - 点「打开授权页面」，在浏览器里用你自己的账号完成授权
  - 回到工作台点「我已完成授权」

  授权对象是你自己的应用，不涉及任何其他人的账号。

【3】创建你的表格

  点第 3 步的「创建」。程序会在【你自己的飞书空间】里新建一张
  多维表格，字段结构（笔记标题 / 笔记类型 / 作者 / 标签 / 正文 /
  点赞数 …）自动建好，之后抓取的笔记都会写进这张表。

【4】配置小红书 Cookie

  没有 Cookie 无法抓取。点第 4 步的「去配置」，会打开设置里的
  「小红书 Cookie」区域。获取方法：
  - 用 Chrome/Edge 打开 xiaohongshu.com 并登录
  - 按 F12 打开开发者工具 → 切到「网络 / Network」标签
  - 刷新页面，点任意一个请求 → 在「请求标头」里找到 Cookie
  - 整段复制，粘贴进去点「保存 Cookie」

  Cookie 会过期（通常几周）。抓取报错「未找到 __INITIAL_STATE__」
  或「Cookie 可能失效」时，回到第 4 步重新粘贴一次即可。

  四步都完成后，引导卡会自动消失。


三、数据存在哪
--------------------------------------------------
- 本地：data\notes.json（抓取结果先存这里，断网也不会丢）
- 云端：你自己的飞书多维表格（建表并登录后自动同步）

页面上带「待同步」标记的记录，表示还没推到飞书。
点顶部的「一键同步到飞书」可以补同步。

「设置 → 数据导出备份」可以把全部数据导出成 CSV 或 JSON 做备份。


四、换电脑怎么办
--------------------------------------------------
把整个文件夹拷到新电脑，双击「启动工作台.bat」即可。

因为 Cookie、飞书应用凭据、登录状态都存在本机系统里，新电脑需要
把四步重做一遍：
  - 重新绑定一次飞书应用（第 1 步）
  - 重新登录一次飞书（第 2 步）
  - 重新点一次「创建」（第 3 步）
  - 重新粘贴一次小红书 Cookie（第 4 步）

如果新电脑上用的是【同一个飞书账号】，又想继续用原来那张表：
把旧电脑 config\settings.json 里的 base_token 和 table_id 复制过来，
在「设置 → 飞书表格坐标（高级）」里填上即可。

本地 data\notes.json 会跟着文件夹一起过去，数据不丢。


五、常见问题
--------------------------------------------------
Q：双击 bat 一闪而过？
A：说明路径里有问题，或没解压。请先完整解压再运行。

Q：浏览器没自动打开？
A：手动打开 http://127.0.0.1:8787

Q：8787 端口被占用？
A：程序会自动换成 8788、8789…，看命令行窗口里显示的地址。

Q：第 1 步点「去创建」后浏览器没反应？
A：在「设置 → 飞书应用」里点「创建 / 更换我的飞书应用」，
   弹窗里会显示链接和一组代码，手动复制到浏览器打开即可。

Q：提示「App ID 或 App Secret 不正确」？
A：去 open.feishu.cn 开发者后台，在「凭证与基础信息」里重新复制
   App ID 和 App Secret（Secret 只显示一次，忘了就重置）。
   校验不通过时程序不会改动本机配置，可以放心重试。

Q：抓取提示 Cookie 失效？
A：重新获取并粘贴 Cookie（见第二节【4】）。

Q：点「创建」提示失败？
A：先确认前两步都完成了。多数情况是应用没有开「创建多维表格」
   相关权限，去开发者后台给应用补上即可。

Q：飞书同步失败？
A：先确认「设置」里飞书是「已登录」、表格显示为已创建，再点一键同步。

Q：杀毒软件报警？
A：因为包内含独立的 Python 运行时和 lark-cli.exe，
   属于正常的绿色软件打包方式，放行即可。


六、目录结构
--------------------------------------------------
  python\           内置 Python 运行时（不用另外装 Python）
  app\              程序代码
    web\index.html  工作台页面
  tools\lark-cli.exe  飞书操作工具
  config\           配置（Cookie、表格坐标，首次运行后自动生成）
  data\             本地数据（notes.json）
  启动工作台.bat     双击运行
  使用说明.txt       本文件

  另有（在用户目录，不在本文件夹里）：
  %USERPROFILE%\.lark-cli\   你自己的飞书应用凭据与登录状态


七、注意
--------------------------------------------------
表格建在你自己的飞书空间里，默认只有你自己能看。
本地 notes.json 只在你自己的电脑上，不会上传到任何别的地方。
本项目不会收集、上传任何数据。
