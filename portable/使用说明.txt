小红书笔记统计台  ·  便携版
==================================================

一、怎么用
--------------------------------------------------
1. 把整个文件夹解压到任意位置（建议放在桌面或 D 盘，路径不要有特殊符号）
2. 双击「启动工作台.bat」
3. 浏览器会自动打开工作台页面（地址通常是 http://127.0.0.1:8787）
4. 把小红书分享链接粘贴到输入框，点「抓取并保存」

使用期间请保持黑色命令行窗口开着，关掉它就等于停止服务。


二、首次使用要配置三样东西
--------------------------------------------------
【1】小红书 Cookie

  没有 Cookie 无法抓取。获取方法：
  - 用 Chrome/Edge 打开 xiaohongshu.com 并登录
  - 按 F12 打开开发者工具 → 切到「网络 / Network」标签
  - 刷新页面，点任意一个请求 → 在「请求标头」里找到 Cookie
  - 整段复制，粘贴到工作台「设置 → 小红书 Cookie」里，点保存

  Cookie 会过期（通常几周）。抓取报错「未找到 __INITIAL_STATE__」
  或「Cookie 可能失效」时，重新复制粘贴一次即可。

【2】飞书登录

  在工作台「设置 → 飞书账号」点「登录飞书」，会弹出授权链接：
  - 点「打开授权页面」，在浏览器里完成飞书授权
  - 回到工作台点「我已完成授权」

【3】创建你自己的表格

  登录成功后，页面顶部会出现蓝色提示条：
  「还没有你的飞书表格」→ 点「立即创建」；
  也可以到「设置 → 飞书账号」点「创建我的飞书表格」。

  程序会在【你自己的飞书空间】里新建一张多维表格，字段结构
  （笔记标题 / 笔记类型 / 作者 / 标签 / 正文 / 点赞数 …）自动建好，
  之后抓取的笔记都会写进这张表。

  ★ 每个账号各有一张自己的表，互相看不到对方的数据。
  ★ 程序不会借用任何人的表格，也无须向别人申请文档权限。


三、数据存在哪
--------------------------------------------------
- 本地：data\notes.json（抓取结果先存这里，断网也不会丢）
- 云端：你自己的飞书多维表格（建表并登录后自动同步）

页面上带「待同步」标记的记录，表示还没推到飞书。
点顶部的「一键同步到飞书」可以补同步。

「设置 → 数据导出备份」可以把全部数据导出成 CSV 或 JSON 做备份。


四、换电脑怎么办
--------------------------------------------------
把整个文件夹拷到新电脑，双击「启动工作台.bat」即可。

因为 Cookie、飞书登录状态都存在本机系统里，新电脑需要：
  - 重新粘贴一次 Cookie
  - 重新登录一次飞书
  - 重新点一次「创建我的飞书表格」（新电脑不知道你的表格地址）

如果新电脑上登录的是【同一个飞书账号】，又想继续用原来那张表：
把旧电脑 config\settings.json 里的 base_token 和 table_id 复制过来，
在「设置 → 飞书表格坐标（高级）」里填上即可。

本地 data\notes.json 会跟着文件夹一起过去，数据不丢。


五、常见问题
--------------------------------------------------
Q：双击 bat 一闪而过？
A：说明路径里有问题，或没解压。请先完整解压再运行。

Q：浏览器没自动打开？
A：手动打开 http://127.0.0.1:8787

Q：8787 端口被占用？
A：程序会自动换成 8788、8789…，看命令行窗口里显示的地址。

Q：抓取提示 Cookie 失效？
A：重新获取并粘贴 Cookie（见第二节【1】）。

Q：登录时提示「你没有 xxx 的使用权限」，账号旁边写着「无权限」？
A：说明这个账号不能用本程序内置的飞书应用。两种办法：
   ① 换成同一家企业里可用的账号登录；
   ② 换成自己创建的应用（推荐给要长期使用的人）：
      用管理员账号打开 open.feishu.cn → 创建「企业自建应用」
      → 开通权限：多维表格 base 的创建与读写、云空间 drive 读、
        offline_access（离线访问）→ 发布应用（可用范围选自己）
      → 然后在本文件夹里打开命令行，执行：

        tools\lark-cli.exe config init --app-id cli_你的应用ID --app-secret-stdin

      粘贴 App Secret 后回车即可。之后重新启动工作台并登录。

Q：点「创建我的飞书表格」失败？
A：先确认飞书是「已登录」状态，再看提示文字；
   多数是应用没有开「创建多维表格」的权限（见上一问第②条）。

Q：飞书同步失败？
A：先在设置里确认飞书是「已登录」、且表格显示为已创建，再点一键同步。

Q：杀毒软件报警？
A：因为包内含独立的 Python 运行时和 lark-cli.exe，
   属于正常的绿色软件打包方式，放行即可。


六、目录结构
--------------------------------------------------
  python\           内置 Python 运行时（不用另外装 Python）
  app\              程序代码
    web\index.html  工作台页面
  tools\lark-cli.exe  飞书操作工具
  config\           配置（Cookie、表格坐标，首次运行后自动生成）
  data\             本地数据（notes.json）
  启动工作台.bat     双击运行
  使用说明.txt       本文件


七、注意
--------------------------------------------------
表格建在你自己的飞书空间里，默认只有你自己能看。
本地 notes.json 只在你自己的电脑上，不会上传到任何别的地方。
